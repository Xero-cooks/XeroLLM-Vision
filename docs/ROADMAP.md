# Roadmap

- Extend the completed dual-T4 CUDA/TensorRT warm benchmarks to diverse real UI datasets, TensorRT-specific HTTP smoke and full precision/quality evaluation.
- Tune engine preparation and inference only after profiling; preserve numerical quality and truthful precision labels.
- Evaluate diverse real UI text, click-target accuracy, small text, rotated text and layout quality.
- Add a verified GPU PNG decoding path; retain explicit format errors until then.
- Integrate additional trusted image-to-text encoders without assuming OCR is full multimodal understanding.
- Verify actual Mercury JSON/tool/SSE behavior and paired throughput with legitimate provider credentials.
- Add request-level deadlines, admission/rate limits, dependency/license audit and supervised deployment guidance.
- Benchmark serializer token reduction using a specified tokenizer rather than claiming an unmeasured percentage.

This list is not a promise of delivered capabilities. See validation evidence for current status.
